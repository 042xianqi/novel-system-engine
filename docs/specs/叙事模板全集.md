## 与现有系统的碰撞结论

**表名精确碰撞**：无（30 个提议表名均未占用）。

**概念重叠**（🔴 不可重复建设）：
`map_state`(38) / `power_state`(24) / `anomaly_state`(14) / `treasure_state`(11) /
`item_state`(4) / `events`(46) / `event_template`(99) / `foreshadow`(12) / `timeline`(53)

**关键**：现有 `*_state` 表带 `source_card` + `source_sha`，是
**Markdown 卡 → 结构化投影**（`02_资料库/地图/LOC-99-001.md` → `map_state`）。
新增表**必须遵守同一约定**（`code` / `source_card` / `source_sha` / `basis`），
否则变成"第二套投影"，重演多权威源问题。
