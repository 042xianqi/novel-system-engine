# 工作流规则（workflow）

按需加载的规则块：**多步骤工程任务的推进纪律**。默认不常驻，模型判断相关时用
`load_rule(rule="workflow")` 拉取。

## 何时用

任务预计需要 3 次以上工具调用、有相互依赖的阶段、或会改动多个文件时——先建计划再动手。

## 纪律

1. **先侦察再动手**：读相关代码，确认既有模式与约定，不要凭想象改。
2. **最小改动**：只改必要的部分，不做无关重构或风格统一。
3. **一步一验**：每步改动后跑测试或构建确认，不假设"应该没问题"。
4. **失败如实报**：命令失败就贴原始报错，不粉饰、不省略。
5. **收尾闭环**：改了共享代码，先看谁依赖它，避免连锁破坏。

## 计划工具

`plan` 工具把子步骤写进会话库并跟踪进度：`replace_active` 建计划，`advance` 推进，
`clear_active` 收尾。计划是给**自己**看的路标，不是给用户看的表演。
