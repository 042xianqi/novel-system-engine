```python
import re
def norm(s):                       # 归一口径
    s = re.sub(r'```[a-z]*', '', s)
    s = s.replace('｜', '|')
    s = re.sub(r'[A-Z]{2,6}-\d{2}-\d{3}', 'CODE', s)
    s = re.sub(r'[A-Z]{2,6}-\d{3}', 'CODE', s)
    s = re.sub(r'^#\s*CODE\|\s*', '# ', s, flags=re.M)
    return re.sub(r'\s+', '', s)
# 磁盘文件 norm(content) 是否 ∈ {norm(materials.content)}
```

必须归一化的原因（实测差异仅来自两处**重编号副作用**）：

1. 导入后 `fix_h1_codes` 给 H1 加了 `CODE｜` 前缀 → 磁盘无、DB 有。
2. 导入后 `rewrite_refs` 把正文里的旧编号改成了新编号（如 `因果线/REL-99-006` → `FORE-99-020`）。
