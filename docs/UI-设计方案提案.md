## 〇、三个方案的共同底线（无论选哪个都照此执行）

1. **单手可达**：废除左上角菜单。底部导航 ≤4 项；「工作台」点按从底部弹出
   宫格抽屉（3 列，每格 ≥68px 高，拇指易点）。
2. **去编号化**：卡片上**绝对不出现** `ARTS-99-902` 这类内部编号。
   大标题最大 → 摘要居中 → 底部小徽章（所属文明 / 分类 / 字数）。
   *注：后端当前不返回「文明」「摘要」字段，需后端补；在此之前该行显示
   后端已有字段（分类/标签/字数），不留空位、不占位。*
3. **详情/大纲全屏抽屉**：一律从**右侧**滑出 `85vw`（桌面封顶 640px）抽屉，
   Markdown 大字排版；遮罩点击 / ✕ / Esc 三关闭；禁居中弹窗。
4. **设置统一化**：单一「API 配置列表」+【＋ 添加】表单
   （名称 / BaseURL / API Key / 模型名），Key 只显尾 4 位。
5. **性能底线**：动效只动 `transform`/`opacity`；不引入图表外的重型依赖
   （ECharts 保持动态导入，主包 <300K）。

| `--bg-elev` | `#141416` | 卡片/浮层 |

### 视觉规则
- **无阴影**：卡片 `border: 1px solid var(--line)`，纸片般轻薄；hover 只把边框提亮到 `#3A3A40`。
- **无圆角滥用**：卡片 8px、按钮 6px、抽屉左侧 0 右侧 12px。
- **层级靠排版**：标题 20/600、正文 14/400、元信息 11/400 且 `--fg-faint`。
  **不用色块**，除状态点外几乎无色。
- 留白慷慨：页面 `px-4 py-4`，卡片内 `p-4`，卡片间 `gap-3`。

## 方案 C（**推荐**）：太墟对齐 · 动态色暗黑极简

### 为什么推荐
用户偏好明确写着「拿不准的一律参考太墟」。本方案=**A 的极简骨架 + 太墟
Material3 动态色**：既得到现代极简观感，又与您天天在用的太墟视觉同源，
未来把 ne-agent 搬进 App 时不会"两套皮"。

### 色彩 Token（直接取太墟）
| 角色 | 值（暗） | 来源 |
|---|---|---|
| `--primary` | `#BAC3FF` | 太墟 `M3ExpDarkPrimary` |
| `--on-primary` | `#0C2792` | `M3ExpDarkOnPrimary` |
| `--primary-container` | `#293FA9` | `M3ExpDarkPrimaryContainer` |
| `--secondary` | `#C3C5DD` | `M3ExpDarkSecondary` |
| `--bg` | `#0F1014` | 近黑（自定，太墟用动态取色可覆盖） |
| `--bg-elev` | `#17181D` | 卡片 |
| `--line` | `#26272E` | 1px |
| `--fg` | `#E9E9EE` / `--fg-dim #9A9AA5` | 主/次文字 |
| 状态 | ok `#3FB950` / warn `#D29922` / bad `#F85149` | 仅小圆点 |

### 与 A 的差异
1. **主色是淡紫蓝 `#BAC3FF`**（太墟暗色主色），用于选中态/关键按钮/图表首色，
   而不是纯白——更"有品牌感"，也不刺眼。
2. **支持跟随系统动态取色**（太墟 `DynamicThemeUtils` 的做法）：读
   Android 动态色（Material You）覆盖 `--primary`，让面板与手机主题同调。
3. 保留 A 的"1px 边框 + 无阴影 + 排版分层"骨架。
